# 整理后清理做种

适用于 MoviePilot V2。在 MoviePilot 成功整理媒体后，插件定时复核相应下载任务；确认可以清理时，通过 MoviePilot 已配置的下载器删除种子任务及其下载文件。媒体库中的已整理文件不属于清理目标。

本插件收录在 `https://github.com/sunbroke555/MoviePilot-Plugins`。将此仓库地址加入 MoviePilot 的 `PLUGIN_MARKET`，刷新插件市场后安装“整理后清理做种”。

## 启用

1. 先在 MoviePilot 中配置并连接 qBittorrent 或 Transmission 下载器，确保 MoviePilot 能查询到下载任务和下载历史。
2. 安装并启用本插件，在“允许清理的下载器”中选择一个或多个下载器，再设置自动清理间隔（默认 10 分钟）。不选择下载器时不会加入新的清理任务，也不会删除已排队任务。首次运行保留默认的**预览模式**，查看候选任务与跳过原因。
3. 核对候选任务后，关闭预览模式才会执行删除。建议先用一个可恢复的测试任务验证下载器路径和媒体库路径。

详情页的“立即执行”按钮可以马上检查待处理列表，无需等待自动清理间隔。启用插件、选好下载器且存在对应待处理种子后按钮可用；手动检查使用当前模式，预览模式只检查，关闭预览才会清理。执行期间会显示处理提示，完成后自动刷新列表及本次结果。手动检查与定时检查不会同时重复执行。

插件会响应启用后的整理完成事件，并按自动清理间隔核对下载器、下载历史和整理记录；每轮符合全部条件就清理，没有额外等待时间。整理事件针对单个文件触发；多文件种子需要等全部应整理的媒体文件成功入库，不能因为第一集整理完成就删掉整包。安装前已经整理的历史任务不会自动加入清理队列。

如果整理后的文件或整个目录已经搬走，可在设置中开启**允许整理目标缺失时清理**（默认关闭）。开启后，原目标路径不存在的文件可凭成功的复制或硬链接整理记录通过检查；插件不会查找或验证新位置的副本，目标实际已丢失时也会放行。已有文件仍会核对类型、大小和硬链接关系，权限或访问错误、软链接、整理失败、未完成整理及共享下载文件仍会跳过。该开关不会关闭预览模式。

预览详情、清理记录详情和日志会注明被忽略的缺失目标路径。确认文件已搬走后开启此选项，再点击“立即执行”即可重新检查原有待处理任务。

升级到 1.1.0 后需在设置中选择允许清理的下载器。只会清理选中下载器中的任务；复核共享数据时仍会查询 MoviePilot 配置的其他下载器，任一下载器不可用时本轮会跳过删除。

## 清理间隔与记录

只需设置“自动清理间隔”。例如设为 10 分钟，就每 10 分钟检查一次待处理种子；整种已安全整理且关闭预览模式时执行清理，否则保留并显示原因。升级到 1.2.0 后沿用原复核周期，旧的“整理后缓冲时间”设置不再生效；旧队列会继续处理。

详情页使用普通背景的主副标题列表：主标题是完整种子名称，副标题是实际整理后的文件名。多文件种子显示首个文件名与已找到成功整理记录的文件数，展开“查看详情”可查看全部名称和 Hash；该数量不代表整种已整理完成。

页面分为“清理记录”和“待处理”两个选项卡，清理记录在前且默认显示，两侧标签显示各自条数。选项卡内直接显示列表，无需展开分组；长列表在列表内部滚动，可查看最近 100 条清理记录。“立即执行”按钮和最近执行结果在两个选项卡上方，切换时始终可见。

待处理状态显示“待检查”“未整理完成”“可清理（预览）”或“已跳过”，并保留具体原因。新删除记录同时保存种子名和整理后文件名，删除后仍可辨认；旧记录会在历史数据可用时补全名称。

## 清理条件

- 下载器必须由 MoviePilot 管理，任务与 MoviePilot 的下载记录能够通过下载器名称和种子 Hash 对应。
- 下载任务已完成，全部已登记文件均有成功的复制或硬链接整理记录，媒体文件与种子清单逐项对应；失败或未完成的整理不会触发删除。默认还需验证整理目标；仅显式开启上述开关时允许原目标路径缺失。
- 软链接整理会被跳过，以免删除下载文件后让媒体库链接失效。
- 多个种子可以使用同一个下载目录；插件按下载器提供的文件清单核对，文件互不重叠时可分别清理。目录内不属于当前种子的文件不会作为当前种子的清理目标。
- 发现辅种或其他任务共用同一个文件时跳过，并显示冲突种子的名称及文件路径。共享目录中其他种子的文件清单无法取得或无法确认时，也会保留当前任务。
- 条件不足、下载器不可用或文件关系无法确认时跳过，并记录原因。

实际删除通过下载器执行，动作包含**删除任务、种子以及下载文件**。请先确认下载器对路径有访问与删除权限；硬链接入库时，删除下载目录中的链接通常不会删除媒体库中的另一条硬链接。

## 运行限制

本插件只处理可由 MoviePilot V2 下载历史、整理历史和下载器任务共同验证的下载内容。手工加入下载器、历史记录缺失、未完成整理、路径不一致、软链接或共享数据的任务会保留。定时复核依赖 MoviePilot 和下载器持续运行，停机或连接失败期间不会执行清理，恢复后会在后续周期重新检查。

预览模式适合先核对规则；关闭预览后，下载器删除文件通常无法撤销。请保留媒体库备份，并根据站点的做种要求设置足够的保种时间。
